Политика конфиденциальности

Приложение: Аркиум
Дата вступления в силу: 1 ноября 2026 г.

1. Общие положения

Настоящая политика описывает обработку данных мобильным приложением «Аркиум». Приложение предназначено для локального хранения и систематизации документов пользователя и разработано по принципу минимизации данных.

2. Какие данные обрабатывает приложение

По выбору пользователя приложение может обрабатывать фотографии и PDF-файлы документов, распознанный текст, названия, категории, теги, сроки действия документов, сведения о местах хранения бумажных оригиналов и настройки приложения.

Разработчик не получает и не хранит эти данные. Они обрабатываются локально на устройстве пользователя. Приложение не использует учётные записи, облачный сервер разработчика, рекламные SDK, аналитику, средства отслеживания или системы удалённой диагностики с передачей данных.

3. Локальная обработка и распознавание текста

Распознавание текста (OCR), обработка изображений, извлечение текста из PDF-файлов и поиск выполняются непосредственно на устройстве. Содержимое документов не отправляется разработчику или в сторонние сервисы для распознавания.

4. Хранение и защита данных

Документы и база приложения хранятся во внутреннем хранилище приложения на устройстве. Содержимое категорий «Личные документы» и «Здоровье», включая файлы страниц, миниатюры и распознанный текст, шифруется с использованием AES-256-GCM. Ключ шифрования хранится средствами защищённого хранилища Android.

Другие категории хранятся локально без указанного дополнительного шифрования приложения. За общую защиту устройства отвечают механизмы Android, включая блокировку экрана и шифрование устройства.

Автоматическое резервное копирование данных приложения средствами Android отключено, чтобы документы и локальный ключ не переносились в облачную резервную копию без явного действия пользователя.

5. Резервные копии и передача документов

Резервная копия создаётся только по команде пользователя. Пользователь самостоятельно выбирает категории и место передачи или сохранения файла через системные средства Android. Категории «Личные документы» и «Здоровье» можно включить в резервную копию только при защите файла паролем.

При использовании функций «Поделиться» или экспорта выбранные документы либо резервная копия передаются приложению или сервису, который выбрал пользователь. После передачи дальнейшая обработка регулируется политикой выбранного получателя. Разработчик не контролирует такие сторонние приложения и сервисы.

Пароль защищённой резервной копии не передаётся разработчику и не может быть им восстановлен. Ответственность за сохранность файла и пароля несёт пользователь.

6. Разрешения Android

Для выполнения выбранных пользователем действий приложение может запрашивать:

  • доступ к камере — для фотографирования документов;
  • доступ к изображениям или выбранным файлам — для импорта фотографий и PDF;
  • разрешение на уведомления — для локальных напоминаний о сроках документов и резервном копировании;
  • получение события загрузки устройства — для работы локально запланированных уведомлений после перезагрузки.

Разрешения используются только для описанных функций. В основной release-сборке отсутствует разрешение на доступ к интернету.

7. Срок хранения и удаление данных

Данные хранятся на устройстве до их удаления пользователем. Отдельные документы можно удалить внутри приложения. Удаление приложения средствами Android удаляет его внутреннюю базу и файлы. Экспортированные документы и резервные копии находятся вне внутреннего хранилища приложения и удаляются пользователем отдельно в месте их сохранения.

8. Дети

Приложение не предназначено специально для детей. Разработчик не собирает данные пользователей, включая данные детей.

9. Изменения политики

При изменении функций приложения или порядка обработки данных обновлённая версия политики будет опубликована по этому же адресу с новой датой вступления в силу.
